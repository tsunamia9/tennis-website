Tennis Website

A multi-page tennis-themed website designed and developed as part of a Haaga-Helia course project.

About the Project

The goal of the project was to create a visually engaging and personal tennis-themed website with a distinctive look and feel.

The project included:

Designing the overall website structure
Creating a multi-page website
Developing the website using HTML and CSS
Designing a distinctive visual style and color palette
Focusing on usability, navigation and clear content structure
Creating a responsive layout
